# מדריך קצר - יומן אבחון מיקום הוידג'ט

התוכנה שומרת תמיד (אין הגדרה להפעלה/כיבוי) יומן טקסט קצר של החלטות
מיקום חריגות של הוידג'ט - כדי לעזור לאתר תקלות עתידיות של הבהוב/
היעלמות עם נתונים אמיתיים, במקום ניחוש.

## מה נרשם ליומן

רק אירועים חריגים (לא כל בדיקת מיקום רגילה כל חצי שנייה) - למשל:

- זיהוי שתפריט ההתחל (או מסך-על דומה של Windows) פתוח, ולכן דילוג
  על עדכון מיקום.
- קפיצת מיקום חשודה (גדולה ופתאומית) שממתינה לאישור חוזר.
- כל מיקום שבאמת הוחל על הוידג'ט בפועל.

זהו יומן קליל מאוד (כמה שורות בודדות לכל היותר בכל דקה, רק באירועים
חריגים) ומוגבל בגודל (מתאפס אוטומטית אם הוא עובר 2MB), כך שאין סיבה
אמיתית לכבות אותו - הוא פעיל תמיד.

## איפה קובץ היומן נמצא

```
%AppData%\HebrewTaskbarWidget\position-diagnostics.log
```

כלומר בדרך כלל (בהחלפת `<המשתמש>` בשם המשתמש בפועל):

```
C:\Users\<המשתמש>\AppData\Roaming\HebrewTaskbarWidget\position-diagnostics.log
```

אפשר להדביק את הנתיב הזה ישירות בסרגל הכתובת של סייר הקבצים (או ב-
Win+R) כדי לפתוח את התיקייה ישירות. הקובץ הוא טקסט רגיל - נפתח בכל
עורך טקסט (Notepad ודומיו).

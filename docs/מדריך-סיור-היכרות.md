# מדריך קצר - תמונות סיור ההיכרות (OnboardingTourWindow)

התוכנה כוללת חלונית "סיור היכרות" (קרוסלת תמונות) שנפתחת אוטומטית בפעם
הראשונה שהתוכנה עולה במחשב חדש, ונגישה גם בכל עת דרך כפתור "הצג סיור
היכרות" בלשונית "כללי" (אחרי חלק העדכונים).

## איפה שמים את התמונות

בתיקייה:

```
src\HebrewTaskbarWidget.SettingsRecovery\Assets\Onboarding\
```

עם השמות (מספור רציף, בלי דילוגים):

```
onboarding-1.png
onboarding-2.png
onboarding-3.png
onboarding-4.png
onboarding-5.png
onboarding-6.png
```

התוכנה מציגה רק את מה שקיים בפועל על הדיסק - אפשר גם להתחיל עם פחות
מ-6 תמונות בלי לשנות שום קוד. **שישה קבצי placeholder כבר קיימים
בתיקייה הזו כרגע** (נוצרו אוטומטית כדי שהתכונה תעבוד "מהקופסה") -
פשוט מחליפים אותם באותם שמות בדיוק עם ה-screenshots האמיתיים.

## גודל מומלץ

**1440 × 900 פיקסלים, יחס 16:10, קובץ PNG.**

התמונה מוצגת בפועל בתוך תיבה בגודל 480×300 בתוך החלונית (עם
`Stretch="Uniform"` - שומר על יחס הגובה-רוחב, לא מעוות) - כלומר גודל
התצוגה הוא בערך פי 3 קטן מהתמונה המקורית, מה שמבטיח חדות גבוהה גם על
מסכים עם קנה-מידה (DPI Scaling) גבוה. תמונה שאינה בדיוק ביחס 16:10
עדיין תוצג כהלכה (ממורכזת, בלי עיוות), אך רק ביחס הזה בדיוק אין
"שוליים ריקים" מסביב לתמונה בתוך התיבה.

## איך מוסיפים יותר מ-6 תמונות

1. מוסיפים את קובצי `onboarding-7.png`, `onboarding-8.png` וכו' לתיקייה
   שלמעלה, באותו גודל/פורמט מומלץ.
2. מוסיפים אותם גם ל-`HebrewTaskbarWidget.csproj` (ליד `onboarding-6.png`
   הקיים, ב-`ItemGroup` שמסומן "תמונות סיור ההיכרות") - **שלב הכרחי**,
   אחרת הקבצים לא ייכללו בפועל בבנייה/בהרצה של התוכנה. פשוט מעתיקים את
   אותה שורת `<Content Include=...>` ומחליפים את המספר.
3. אין צורך בשום שינוי קוד נוסף - מספר הנקודות (dots) בתחתית התמונה,
   הניווט בין השקופיות, וזמינות הכפתור בלשונית "כללי" כולם מתעדכנים
   אוטומטית לפי כמות התמונות שנמצאה בפועל על הדיסק.

## התנהגות "דלג" מול "הזכר לי אחר כך"

- **דלג** - הסיור לא יוצג יותר אוטומטית לעולם (עדיין ניתן להריץ אותו
  ידנית מלשונית "כללי" בכל עת).
- **הזכר לי אחר כך** - הסיור יוצג שוב אוטומטית בפעם הבאה שהתוכנה עולה
  (למשל אחרי הפעלה מחדש של המחשב).

## השבתה זמנית מלאה (לצורכי פיתוח/בדיקה בלבד)

לפעמים רוצים להשבית זמנית את כל התכונה (גם ההצגה האוטומטית וגם כפתור
"הצג סיור היכרות" בלשונית "כללי") בלי למחוק/לשנות קוד בכלל - למשל
כדי לבודד בעיה אחרת בלי שהחלונית תקפוץ תוך כדי בדיקות.

**הדרך הכי פשוטה: מוסיפים תו אחד לשם התיקייה.**

התוכנה מחפשת תמונות במפורש בנתיב:

```
Assets\Onboarding\onboarding-N.png
```

אם משנים את שם התיקייה `Assets\Onboarding` (למשל מוסיפים קו-תחתון
בהתחלה, כך שהיא נהיית `Assets\_Onboarding`) - התוכנה פשוט לא מוצאת
אף תמונה בנתיב שהיא כן מחפשת, וכתוצאה מכך:

- הסיור לא יוצג יותר אוטומטית בעליית התוכנה.
- לחיצה על "הצג סיור היכרות" בלשונית "כללי" תציג הודעה קצרה שאין
  תמונות סיור מוטמעות, במקום לפתוח את הסיור.

**להחזיר את זה בחזרה:** פשוט משנים את שם התיקייה בחזרה ל-
`Assets\Onboarding` (מסירים את התו שהוספתם) ובונים מחדש - הכל חוזר
לעבוד בדיוק כמו קודם, בלי שום שינוי קוד בשום שלב.

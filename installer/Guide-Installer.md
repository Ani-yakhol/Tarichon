# מדריך מעטפת ההתקנה של תאריכון (Inno Setup)

מדריך זה מסביר איך לבנות את קובץ ההתקנה (Setup.exe) של תאריכון, מה כל
חלק בסקריפט עושה, ואיך להתאים אישית את הדברים המרכזיים.

## תוכן החבילה

```
Tarichon-Setup.iss         <- הסקריפט הראשי של Inno Setup
Guide-Installer.md         <- המדריך הזה
License\
  License-he.txt            <- טקסט הרישיון (מוצג ומחייב אישור בהתקנה)
Languages\
  Hebrew.isl                 <- קובץ שפה עברי מלא (RTL) עבור Inno Setup
Icons\
  app.ico                    <- אייקון התוכנה
  WizardSmall.png             <- תמונה קטנה שנוצרה מהאייקון, לתצוגה בפינת חלונית ההתקנה
App-Files\                 <- כאן מניחים את קבצי הפרסום של התוכנה הראשית (ראו שלב 1)
SettingsRecovery-Files\    <- כאן מניחים רק את HebrewTaskbarWidgetSettings.exe
Redist\                    <- (ריקה כברירת מחדל) - למתקין ה-.NET, רק במצב "הכללה מקומית"
Output\                    <- כאן ייווצר קובץ ה-Setup הסופי לאחר קימפול
```

**שימו לב:** חבילת ההתקנה הזו נשלחת אליכם כקובץ דחוס **נפרד** מהתוכנה
עצמה. בכל פנייה עתידית נציין במפורש אם מדובר בתיקון למעטפת ההתקנה או
לתוכנה "תאריכון" עצמה.

## דרישות מוקדמות

1. **Inno Setup 6** (הגרסה החינמית) - להורדה מ-
   https://jrsoftware.org/isdl.php - יש להתקין את הגרסה הרגילה (לא
   ה-QSP), שכוללת את ה-IDE (Compiler) ואת ISCC.exe לקימפול משורת הפקודה.
2. **.NET 8 SDK** (להריץ `dotnet publish`) - אם כבר בניתם/הרצתם את
   הפרוייקט ב-Visual Studio, כנראה שכבר מותקן אצלכם.

## שלב 1: פרסום (Publish) והנחת הקבצים בתיקיות

התוכנה מפורסמת במצב **תלוי-Framework** (Framework-Dependent) - כלומר
קובץ ה-exe עצמו קטן, אך דורש שה-**.NET 8 Desktop Runtime** יהיה מותקן
במחשב שמריץ אותו. זו הסיבה שהתקנת ה-Runtime משולבת בקובץ ההתקנה (ראו
שלב 3 למטה).

מתיקיית `src` של הפרוייקט (**לא** מתיקיית מעטפת ההתקנה), יש להריץ:

```bash
dotnet publish HebrewTaskbarWidget -c Release -r win-x64 --self-contained false
dotnet publish HebrewTaskbarWidget.SettingsRecovery -c Release -r win-x64 --self-contained false
```

לאחר מכן:

| מה | מאיפה | לאן |
|---|---|---|
| **כל** תוכן הפרסום של התוכנה הראשית | `src\HebrewTaskbarWidget\bin\Release\net8.0-windows10.0.19041.0\win-x64\publish\` (כל התיקייה, כולל תיקיות משנה) | `App-Files\` |
| **רק** הקובץ הבודד HebrewTaskbarWidgetSettings.exe | `src\HebrewTaskbarWidget.SettingsRecovery\bin\Release\net8.0-windows10.0.19041.0\win-x64\publish\HebrewTaskbarWidgetSettings.exe` | `SettingsRecovery-Files\` |

(אין צורך להעתיק את שאר קבצי ה-DLL של כלי ההגדרות - הם זהים לגמרי
לאלה שכבר הועתקו מ-App-Files, כי שני הפרוייקטים חולקים את אותה תשתית.)

בכל אחת משתי התיקיות האלה יש קובץ טקסט עם הנחיות דומות - אפשר למחוק
אותו אחרי שהעתקתם את הקבצים האמיתיים.

## שלב 2: עדכון פרטי הפרסום והרישיון

בראש `Tarichon-Setup.iss`, עדכנו לפי הצורך:
- `MyAppPublisher` - שם היוצר/הארגון שלכם.
- `MyAppURL` - כתובת אתר/עמוד התוכנה, אם יש.

ב-`License\License-he.txt`, יש להשלים את השורה:
`בעל זכויות היוצרים בתוכנה הוא [שם המפתח / בעל הזכויות - נא להשלים].`

## שלב 3: החלטה על מצב הכללת .NET Desktop Runtime 8

התוכנה בודקת בזמן ההתקנה (ראו הסבר מלא ב"פונקציות שהוטמעו" למטה) האם
**.NET 8 Desktop Runtime x64** כבר מותקן במחשב היעד. אם כן - כל התהליך
מדולג לגמרי, בלי שום השפעה על ההתקנה. אם לא - ההתנהגות תלויה במצב
ההפצה (ראו למטה). קיימים שני מצבי הפצה, נשלטים ע"י שורה אחת בראש הסקריפט:

```pascal
#define IncludeDotNetRuntime false   ; או true
```

### מצב `false` (ברירת המחדל) - "מקוון" / הפצה קלה
- קובץ ה-Setup **לא כולל בכלל** את מתקין ה-.NET (חוסך כ-50-60 מ"ב).
- אם ה-Runtime חסר, **שואלים את המשתמש אישור מפורש** (כן/לא) לפני
  שמורידים אותו - **דורש חיבור אינטרנט פעיל** באותו רגע. אם המשתמש
  לוחץ "לא", ההתקנה ממשיכה כרגיל בלי ה-Runtime (התוכנה עצמה עלולה לא
  לפעול כראוי עד שיתקינו אותו ידנית).
- זהו המצב שכבר מוגדר כברירת מחדל - **אין צורך בשום פעולה נוספת**.

### מצב `true` - "לא-מקוון" / הפצה עצמאית
מתאים אם ברצונכם שקובץ ה-Setup יעבוד גם במחשב **בלי אינטרנט בכלל**. אם
ה-Runtime חסר, הוא מותקן **אוטומטית ובשקט לגמרי** (בלי לשאול, ובלי שום
חלונית מהמתקין של מיקרוסופט עצמו) - כי הקובץ כבר ארוז בפנים מלכתחילה.

**שני השלבים הבאים חובה, שניהם - לא מספיק לבצע רק אחד מהם:**

1. הורידו את הקובץ `windowsdesktop-runtime-8.0-win-x64.exe` מ-
   https://dotnet.microsoft.com/download/dotnet/8.0, והניחו אותו
   בתיקיית `Redist\` (בדיוק בשם הזה).
2. **בנוסף** (זו הטעות הנפוצה ביותר) - שנו בראש `Tarichon-Setup.iss`
   את השורה בפועל ל-`#define IncludeDotNetRuntime true`. **רק להניח
   את הקובץ בתיקייה, בלי לשנות את השורה הזו, לא מספיק** - הקובץ
   פשוט לא ייכלל בהתקנה בכלל, וזה יקרה **בלי שום הודעת שגיאה בקימפול**
   (ה-Compiler פשוט "מדלג" על השורה שמכלילה את הקובץ, כי התנאי
   `#if IncludeDotNetRuntime` הוא false).
3. קמפלו מחדש.

אם שכחתם את שלב 2, תוכלו לוודא שזה אכן הבעיה: קובץ ה-Setup שנוצר יהיה
הרבה יותר קטן ממה שהייתם מצפים (מתקין ה-.NET הרשמי הוא כ-50-60 מ"ב).

## שלב 4: קימפול

**דרך ה-IDE:** פתחו את `Tarichon-Setup.iss` ב-Inno Setup Compiler,
ולחצו F9.

**דרך שורת הפקודה:**
```bash
"C:\Program Files (x86)\Inno Setup 6\ISCC.exe" Tarichon-Setup.iss
```

קובץ ה-Setup הסופי ייווצר בתוך `Output\Tarichon-Setup-0.4.8.exe`
(המספר יתעדכן אוטומטית לפי `MyAppVersion` בראש הסקריפט).

## פונקציות שהוטמעו בקובץ ההתקנה - הסבר קצר

- **רישום בריגסטרי** - מעבר לרישום ההסרה הסטנדרטי, כותב רשומה משלו
  תחת `Software\Tarichon` (ב-HKCU, כי ההתקנה תמיד עבור המשתמש הנוכחי
  בלבד - ראו למטה) עם נתיב ההתקנה והגרסה - נמחקת אוטומטית בהסרה.

- **התקנה למשתמש הנוכחי בלבד** - בלי לשאול, ובלי צורך בהרשאות מנהל
  מערכת (מותקן ב-`%LocalAppData%\Programs`, לא ב-Program Files).

- **הסכם רישיון** - חובה לאשר לפני שממשיכים, כולל קרדיט ל-Hebcal.com.

- **קיצורי דרך** - בתפריט התחל (תמיד, לשני היישומים) ועל שולחן העבודה
  (שני קיצורי דרך אופציונליים נפרדים, מסומנים כברירת מחדל).

- **הפעלה אוטומטית עם Windows - מסונכרנת עם התוכנה עצמה** (חדש): עמוד
  "פעולות נוספות" בהתקנה כולל תיבת סימון "הפעלת תאריכון אוטומטית עם
  עליית Windows" (מסומנת כברירת מחדל, כמו בתוכנה עצמה). הסימון הזה
  **כותב בדיוק את אותה רשומת Registry** שהתוכנה עצמה הייתה כותבת אילו
  המשתמש היה מפעיל את ההגדרה המקבילה מתוכה (`Software\Microsoft\Windows\
  CurrentVersion\Run`, עם אותו שם ערך ואותו דגל `--autostart` שהתוכנה
  יודעת לזהות) - כך ששני המקומות (ההתקנה וההגדרות הפנימיות של התוכנה)
  תמיד "מדברים" על אותו ערך רישום בדיוק, ולא יוצרים התנגשות.
  בנוסף, בהתקנה ראשונה **ונקייה בלבד** (אם עדיין אין קובץ הגדרות בכלל),
  ההתקנה גם יוצרת קובץ `settings.json` מינימלי עם הערך התואם - כדי
  שגם התצוגה בתוך חלונית ההגדרות של התוכנה תשקף מיד את הבחירה. בהתקנות
  עדכון/חוזרות שבהן כבר קיים קובץ הגדרות, ההתקנה **לא נוגעת בו בכלל**
  (כדי לא לקחת שום סיכון לפגוע בהתאמות אישיות קיימות) - הסנכרון בפועל
  (מה שבאמת קורה במחשב) עדיין מתבצע במלואו דרך הרישום.

- **בדיקה/התקנה שקטה של .NET Desktop Runtime 8** - ראו שלב 3 למעלה.

- **הסרת התקנה יסודית - משחזרת את שורת המשימות למצב הרגיל** (חדש):
  בעבר, הסרת התקנה רק מחקה קבצים. עכשיו, אם המשתמש אי-פעם השתמש
  באפשרות "הסתר את תצוגת התאריך/שעה המקורית" (עם או בלי "צמצום הרווח")
  בתוך התוכנה, הסרת ההתקנה **מנקה את ערך המדיניות שהתוכנה קבעה
  ב-Registry** (`HideClock` תחת `...\Policies\Explorer`) **ומפעילה
  מחדש את Explorer** (סוגרת את כל תהליכי explorer.exe הקיימים ומפעילה
  אותו מחדש) - זה בדיוק אותו מנגנון שהתוכנה עצמה משתמשת בו כדי לבטל
  את ההסתרה/הצמצום, ולכן זו החזרה **אמיתית ומלאה** למצב המקורי (לא רק
  "מציגה את השעון שוב", אלא גם מחזירה את הרווח שצומצם). בנוסף, מוחקת
  גם את רשומת ההפעלה האוטומטית עם Windows, אם נוצרה.

- **ממשק הסרה בעברית מלאה, RTL** - קובץ Hebrew.isl (כולל
  `RightToLeft=yes`) משמש **גם** את תוכנית ההתקנה **וגם**, באופן
  אוטומטי לגמרי (Inno Setup תמיד מטמיע את אותו קובץ שפה משני הכיוונים),
  את תוכנית ההסרה שנוצרת ממנה - אין צורך בשום הגדרה נוספת כדי שגם
  ההסרה תהיה בעברית מיושרת RTL.

- **מחיקת נתוני ריצה בהסרה** - תיקיית ההגדרות
  (`%AppData%\HebrewTaskbarWidget`) נמחקת גם היא בהסרה.

- **סגירת התוכנה בזמן עדכון** - אם התוכנה פועלת ברקע בזמן התקנת גרסה
  חדשה, Inno Setup מציע לסגור אותה אוטומטית לפני העתקת הקבצים.

## איך להשתמש באייקונים

יש **שני מקומות שונים** שאפשר להטמיע בהם אייקון:

1. **`SetupIconFile=Icons\app.ico`** - אייקון **קובץ ה-Setup עצמו**
   (ומתוכנית ההסרה), וגם האייקון בפינה השמאלית העליונה של **שורת
   הכותרת** של חלון ההתקנה.

2. **`WizardSmallImageFile=Icons\WizardSmall.png`** - תמונה **בתוך**
   חלונית ההתקנה עצמה - מוצגת בפינה בכל אחד מעמודי האשף, נותנת מראה
   "ממותג" עם לוגו התוכנה.

**כדי להחליף לאייקון/לוגו משלכם:**
- `SetupIconFile` - שימו קובץ `.ico` אחר ב-`Icons\app.ico`.
- `WizardSmallImageFile` - שימו קובץ `.png` מרובע (מומלץ ~190×190
  פיקסלים) ב-`Icons\WizardSmall.png`. Inno Setup 6.1+ תומך ב-PNG;
  בגרסאות ישנות יותר יש להשתמש ב-`.bmp` בגודל 55×58 במקום.

יש גם `WizardImageFile` (לא הוגדר) - התמונה הגדולה שמופיעה לאורך הצד
של עמודי "ברוכים הבאים"/"סיום" בלבד. אפשר להוסיף גם אותה באותו אופן.

## הערות תאימות

- Inno Setup **ישן יותר מ-6.3**: יש להחליף `x64compatible` ב-`x64`
  (ב-`ArchitecturesAllowed`/`ArchitecturesInstallIn64BitMode`).
- Inno Setup **ישן יותר מ-6.1**: `WizardSmallImageFile` לא תומך ב-PNG
  - יש להמיר ל-`.bmp` ולעדכן את שם הקובץ בסקריפט.
